# Harry Potter RAG System

This project implements a Retrieval-Augmented Generation (RAG) system for answering questions based on the Harry Potter book series using a Large Language Model (LLM).

## Project Goal

To create an interactive system allowing users to ask questions about the plot, characters, locations, and other details from the Harry Potter books and receive accurate answers generated by an LLM, grounded in the original text of the books.

## Setup

1.  Create and activate a virtual environment (recommended).
2.  Install dependencies:
    ```bash
    pip install -r requirements.txt
    # Or if using pyproject.toml and poetry/pip-tools:
    # poetry install # or pip-sync requirements.txt
    ```
3.  Install pre-commit hooks:
    ```bash
    pre-commit install
    ```

## Linters and Formatters

This project uses `ruff` for linting and formatting Python code.
- To check code manually: `ruff check .`
- To format code manually: `ruff format .`
These checks are automatically run before each commit via pre-commit hooks.
